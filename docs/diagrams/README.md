## Rendering contract

The Markdown image URL pattern is:

```text
https://www.plantuml.com/plantuml/proxy?cache=no&src=https://raw.githubusercontent.com/Gitbub0816/strijder/main/docs/diagrams/<diagram>.puml
```

This keeps the text source canonical and allows GitHub or a browser to request the rendered SVG directly from PlantUML.
